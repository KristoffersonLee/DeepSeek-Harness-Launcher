DSHLauncher 新手指引

一、端口是什么？要不要改？

端口就是电脑给程序开的"门"。DSH Harness 默认使用 3080 端口，浏览器通过 http://127.0.0.1:3080 访问它。

  • 默认不用改，直接用就行；
  • 只有一种情况需要改：提示"端口被占用"且占用的不是 Harness 时，换一个数字（比如 3090）；
  • 端口范围 1~65535，随便选个没被占用的就行。

二、工作目录是什么？怎么选？

工作目录是 Harness"干活"的地方：它在这里保存会话记录，也是它读写文件的范围。

  • 想让它帮忙处理日常文件 → 选桌面（需要你在设置里手动把工作目录填成桌面路径）；
  • 想让它专注某个项目 → 选那个项目文件夹；
  • 换了目录等于换了一个新工作区，之前的会话不会丢，也不会混在一起。

三、环境要求（一般不用管）

启动器会自动检测 Node.js 和 dsh。需要它们时：

  • 安装 Node.js LTS 版本；
  • 打开命令行执行：npm install -g @deepseek-ai/dsh

四、常见问题

快捷键（在主界面窗口内）：

F5 / Ctrl+R — 刷新界面

Esc — 按「关闭主界面窗口时最小化到托盘」偏好隐藏或关闭窗口

注：本指引窗口与设置窗口不响应上述快捷键（避免影响页面里的输入）。

更多问题请查看维护手册。
